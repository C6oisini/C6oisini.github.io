**一句话**：扰动旧记忆但固定任务、动作、观察和参考输出，限制下一步内部表示对旧错误的放大。

## 为什么需要

递归 memory 每次都把上一版文本当输入。旧错误若使下一表示发生更大偏移，就可能在连续重写中被放大。像复印件上的污点每复印一次都更黑，需要限制复印系统对小污点的增益。

## 怎么做

对 incoming memory $p_{t-1}$ 生成扰动版 $\tilde p_{t-1}$，保持其余输入与 teacher-forced reference output 不变，得到单位投影 $q_t$、$\tilde q_t$：

$$
\rho_t=\frac{\|q_t-\tilde q_t\|_2}
{\|\phi(p_{t-1})-\phi(\tilde p_{t-1})\|_2+\delta},
\qquad
L_{\mathrm{US}}=\mathbb E[\max(0,\rho_t-1)^2].
$$

- 分母衡量输入 memory 在冻结 encoder 空间的变化，分子衡量更新表示的变化。
- 只惩罚 $\rho_t>1$ 的 pair；实现可对 clean branch stop-gradient，让梯度从 perturbed branch 回传。

## 适用边界

它只约束抽样文本扰动上的内部 projection，不是 decoded memory 的全局 contraction。扰动应带事实标签，否则“变化小”可能只是忽略了有效新证据。必须监控 projection 方差，防止 near-constant representation 投机；还要单独评估正确事实保留和错误纠正。
