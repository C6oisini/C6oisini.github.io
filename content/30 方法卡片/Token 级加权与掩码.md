**一句话**：同一段文本里，不是每个 token 都值得给梯度；正样本按"还没学会"降权已收敛位置，负样本按"错在哪里"屏蔽局部正确的 token。

## 为什么需要

自蒸馏时均匀算 KL，梯度会大量花在模型已经学会的位置上（比如格式化输出、简单代入），真正需要学的那几个推理跳跃反而被稀释。RL 惩罚负样本时更糟：一条错轨迹里大半 token 是对的，全罚会把通用推理技能一起打掉，而且低概率低熵的异常 token 会主导梯度。

## 怎么做

正样本用权重，两个互补信号做 Soft-OR，只要有一个高就不降权：

$$
w(t) = \hat{H}(t) + \hat{\Delta}(t) - \hat{H}(t)\hat{\Delta}(t)
$$

- $\hat{H}(t)$：学生熵，按样本归一化到 $[0,1]$，越高表示越不确定
- $\hat{\Delta}(t)$：教师与学生分布的 KL，归一化，越高表示差得越多
- 两项都低 = 学生既确定又和教师一致 = 已收敛，权重趋近 0

负样本用掩码，按"低概率 × 高确定度"排序，取前 50%：

$$
s(t) = -\log p_t(y^{(t)})\cdot\left(1-\hat{H}(t)\right), \qquad m(t) = \mathbb{1}\left[s(t) \geq \mathrm{median}(\{s\})\right]
$$

- $-\log p_t(y^{(t)})$：这个 token 的负对数概率，要保留**未归一化**的量纲，否则罕见但正确的数学符号会被误伤
- $(1-\hat{H}(t))$：确定度
- $m(t)$：掩码，1 表示参与惩罚

## 适用边界

- 加权和掩码都假设"熵低 = 已学会"，但低熵更可能只是模板化输出，不一定是真学会
- 掩码比例 50% 是经验值，参考实现里没有给敏感性分析
- 只在"梯度窗口覆盖整条推理链"时成立。只更新前 N 个 token 的话，长轨迹的前 N 个 token 可能全是铺垫
