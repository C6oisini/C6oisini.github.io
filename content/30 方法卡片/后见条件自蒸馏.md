**一句话**：在线只跑一次、没有参考答案时，别让学生硬背自己刚写的那句话，让一个冻结的初始模型看完这条成功轨迹再逐词给分布，学生对齐整段分布。

## 为什么需要

在线学习最直觉的做法是：这一局成功了，就把它整条轨迹当标签，做 SFT 或策略梯度。

问题出在标签的形态上。轨迹是当前策略自己生成的，每一步只有一个采样到的 token，没有「这一步本来可以怎么走」的信息。在单条轨迹上做硬目标拟合，梯度只会把刚生成的那个 token 抬高、把其余 token 按现值压走——分布越训越尖，最后收敛到「只会重复自己」。在线场景下更糟：下一局的轨迹来自已经被压尖的模型，误差自我放大。

真正的信息在「这局成了」这个信号里，不在那几个 token 上。要把它用起来，需要一个能看到「这局是怎么成的」的判断者，把整局的经验翻译成每个位置上「应该往哪走」的分布。

## 怎么做

**教师 = 冻结的初始模型 + 特权信息**。教师不动，所以它不会跟着学生漂；它额外看到完整轨迹，所以它知道后事。

在学生的前缀 $c$（学生自己跑出来的那一段上下文）上，教师给出下一 token 分布：

$$
q(\cdot \mid c) = \operatorname{stopgrad}\Bigl[p_{\theta_0}\bigl(\cdot \mid z \oplus c\bigr)\Bigr]
$$

先说这个式子在算什么：让冻结的初始模型先读一遍特权信息 $z$，再接着读学生走到这一步的上下文 $c$，输出它对下一个词的完整概率分布，并把这个分布当成固定靶子。

- $\theta_0$：初始权重，全程冻结。教师不加载第二份模型，只把学生的适配器关掉。
- $z$：特权信息，学生看不到。典型内容是「任务目标 + 一句成功声明 + 每个有效步骤的响应文本」。
- $c$：学生前缀，长度随回合增长。
- $\operatorname{stopgrad}$：不往回传梯度。

学生去对齐它，用 forward KL：

$$
\mathcal{L}(\phi) = \sum_{(t,j)} \alpha_{t,j}\, D_{\mathrm{KL}}\bigl(q_{t,j}\,\|\,p^\phi_{t,j}\bigr),
\qquad
\alpha_{t,j} = \bigl(|\mathcal{I}|\,L_t\bigr)^{-1}
$$

- $\phi$：可训练的适配器参数（这里是 LoRA）。基座不动。
- $|\mathcal{I}|$：有非空响应的回合数。$L_t$：第 $t$ 回合的 token 数。
- $\alpha_{t,j}$：先按回合内平均、再按回合间平均，防止长回合主导梯度。

为什么必须换掉硬目标，看两个梯度就清楚。记 $p^\phi$ 是学生分布、$e_y$ 是生成 token 的 one-hot：

$$
\nabla_{\ell_\phi}\bigl[-\omega\log p^\phi_y\bigr] = \omega\,(p^\phi - e_y),
\qquad
\nabla_{\ell_\phi} D_{\mathrm{KL}}\bigl(q\,\|\,p^\phi\bigr) = p^\phi - q
$$

前一个把 $y$ 抬高 $\omega(1-p^\phi_y)$、把其他 token 按压 $\omega p^\phi_k$ 的比例压下去，方向永远是「更相信刚才那个词」。后一个把每个 logit 推 $q_k - p^\phi_k$，直到 $p^\phi = q$。前者只有一维监督，后者是整个词表的监督。

**门控**：只在验证通过时更新，失败就跳过。

$$
\phi_{i+1} = \begin{cases}\mathrm{Evolve}(\phi_i;\ \mathcal{L}_i), & v_i = 1\\ \phi_i, & v_i = 0\end{cases}
$$

- $v_i$：这一局的验证结果，0 或 1。
- $\mathrm{Evolve}$：几步优化器更新（原论文是 AdamW 两步，学习率 $1.5\times10^{-4}$）。

**特权信息的构造**有两种常见做法。一是直接序列化整条成功轨迹；二是先按「动作有没有被环境真的执行」过滤，只把有效回合写进 $z$，但训练位置仍然保留全部回合。后者能让教师给出「如果当初直接做对」的分布，代价是教师输入和学生前缀不再完全对齐。

## 适用边界

- **必须有冻结副本和完整 logits**。教师的输出是一整个词表上的分布，闭源 API 拿不到，只能在开放权重模型上用。
- **必须有可靠的二元验证信号**。整套方法把 $v=1$ 当成「这条轨迹值得学」，验证器有噪声时会把错的轨迹当教材。没有验证信号就没有门控。
- **特权信息不能泄漏答案本身**。如果 $z$ 里放的是参考答案原文，教师可能只是在复述答案、或者在重建学生已经写出的 token，后见就不再独立。判断办法是把 $z$ 的文本换成只含动作的版本看效果掉多少。
- **教师不会跟着学生变**。想让它跟着，只能慢慢跟（EMA 或隔很久快照），而且已有实验显示跟得越快越容易崩。
- **蒸馏位置必须和训练位置一致**。学生训练的每个位置，教师都必须能读到同一段前缀，否则比较的是两个不同的上下文。

三个引子：$z$ 为空时退化成普通 on-policy 蒸馏；$z$ 是参考答案时是 OPSD；$z$ 是环境反馈时是 SDPO 一类的做法。这条谱系统一在「教师比学生多看到什么」这一个维度上。
