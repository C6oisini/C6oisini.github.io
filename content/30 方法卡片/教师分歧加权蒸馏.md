**一句话**：同一段前缀上让教师分别带新旧两份特权信息各看一遍，两个分布差得越远的 token，蒸馏权重越高。

## 为什么需要

把一条改进链压进权重时，新旧两版参考的差别只集中在少数 token 上：某一步换了个公式、某个中间量重算了一遍，其余位置几乎一样。

如果对所有 token 均匀加权，学习预算被大量没变化的位置摊薄；而如果直接用新教师覆盖旧监督，又会丢掉“旧参考下本来正确的部分”。需要一种逐 token 的重要性：只在教师改主意的地方加重。

## 怎么做

学生先在只有 $q$ 的上下文里生成 $y_0$，然后用两个教师分布在同一前缀上的差异给每个 token 算权重：

$$
d_t = \mathrm{TV}\!\left(
\pi_{\theta_0}(\cdot\mid q,a_1,y_{0,<t}),\;
\pi_{\theta_0}(\cdot\mid q,a_2,y_{0,<t})
\right)
$$

$$
\omega_t = 1-\alpha + 2\alpha\,\frac{d_t}{d_t+\tau}
$$

$$
\mathcal{L}_{\mathrm{Acc}}
= D_\omega\!\left(\mathrm{sg}\left[\pi_{\theta_0}(\cdot\mid q,a_2)\right] \,\middle\|\, \pi_\theta(\cdot\mid q)\right)\Big|_{y_0}
$$

先说这三个式子在算什么：先量两个教师在同一前缀下对下一个 token 的分歧，再把分歧映射成 $[1-\alpha,\,1+\alpha]$ 区间的权重，最后用这个权重做一次带权蒸馏。

- $d_t$：两个教师分布的 total variation 距离，取值 $[0,1]$。
- $\omega_t$：第 $t$ 个 token 的权重；$d_t=0$ 时是 $1-\alpha$，$d_t\to1$ 时接近 $1+\alpha$。
- $\alpha$：权重幅度，控制“分歧位置”相对“无分歧位置”的重要程度。
- $\tau$：平滑项，避免 $d_t$ 很小时权重跳变。
- $D_\omega$：按 $\omega_t$ 加权的 KL。

基准权重 $1-\alpha$ 保证所有 token 仍被监督，只是分歧位置被放大。原论文取 $\alpha=0.5$、$\tau=10^{-4}$。

## 适用边界

- 两份特权信息必须只差“改进方向”。如果它们来自不同题目或不同任务，TV 距离大反映的是无关差异，加权会把噪声当信号。
- 需要两次教师前向，训练成本上升；教师很大时这笔开销不可忽略。
- $\alpha$ 和 $\tau$ 是手调的：$\alpha$ 太大等于只看少数 token，太小等于退化成均匀蒸馏。
- 只在 token 级分布可对齐（同一词表、同一 tokenizer）时成立。
