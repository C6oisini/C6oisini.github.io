**一句话**：多轮 agent 在还没学会动作格式时，用逐轮提示先凑出一批「动作正确、推理自写」的轨迹，再交给 RL 精调。

## 为什么需要

基座模型从没见过自定义的动作协议。合法动作序列的初始概率接近零，RL 采出来的轨迹全是解析失败的废样本，组内奖励全同分，优势恒为零，学不动。直接拿外部教师的完整轨迹做模仿又有两个毛病：教师的推理风格会被照搬；模型只会复述示范，不知道动作要按环境反馈调整。

## 怎么做

先让策略自己采，只保留动作等于金标的轮次；金标动作由启发式规则提出，并且要经过真实评估确认有收益才留下。

$$
(z_{t,k}, a_{t,k}) \sim \pi_{\theta_0}(\cdot \mid c_{t,k}, h_{t,k}), \qquad \text{retain only if } a_{t,k} = a^\star_{t,k}
$$

- $\pi_{\theta_0}$：加了新 LoRA 的初始策略。
- $c_{t,k}$：第 $k$ 轮上下文（query、环境状态、动作历史）。
- $h_{t,k}$：这一轮的提示，指明目标动作并解释为什么。
- $a^\star_{t,k}$：金标动作。
- 只有动作对上才留，推理 $z_{t,k}$ 用的是策略自己写的版本。

收集完删掉所有提示，上下文 token 从 loss 里 mask 掉，只监督推理与动作块：

$$
\mathcal{L}_{\text{SFT}}(\theta) = -\mathbb{E}_{\mathcal{D}_{\text{SFT}}}\Big[\omega_z \log \pi_\theta(z_{t,k} \mid c_{t,k}) + \omega_a \log \pi_\theta(a^\star_{t,k} \mid c_{t,k}, z_{t,k})\Big]
$$

- $\omega_z$：推理 token 权重，通常给 1。
- $\omega_a$：动作 token 权重，这篇给 4。

动作块 token 少但决定成败，按 token 平均会让长推理稀释动作的学习信号。Agentic-TTT 里 $\omega_a$ 从 1 提到 4，最终 utility 0.464 → 0.510，无效动作率 4.08% → 1.72%。

## 适用边界

- 需要可信的金标动作。这篇用启发式规则加 TTT 实测确认，代价是要真跑一遍适应；没有可靠来源时，蒸馏学的是错的动作。
- 提示必须清干净。残留的 hint 会让模型在部署时等提示；这篇在构造 SFT 数据和评测时都移除了。
- 蒸馏只给先验。动作频率、该不该动手这类取舍仍然要靠 RL 校准，否则模型只会复现示范里的比例。
- 上下文 mask 掉，否则模型会学会复读观察而不是学会动作。
